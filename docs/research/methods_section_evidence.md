# Evidence for the added Methods sections

The new sections in `docs/methods.tex` are additive. Existing model claims and historical implementation prose are not rewritten in this draft.

- **Implemented arithmetic options and current scope:** `docs/GIBBS_OPTIMIZATIONS.md`, `src/pegs_shared/gibbs_features.py`, `src/pegs_shared/grouped_regression.py`, `src/pegs_shared/compiled_moments.py`, and the HuGE normalization branch in `src/pigean/state.py`. The design was already sparse; the new work makes regression arithmetic sparse/grouped and reuses fixed structure. The default arithmetic remains legacy and options remain independently selectable.
- **Full T2D benchmark:** the analysis master tracker, `plans/optimization_tracker.md` outside this code checkout, records historical legacy 6201.42 s / 2.479 GiB; contemporaneous first milestone 852.63 s; optimized seven-extension stack 309.42 s / 1.486 GiB. The 20.04-fold and 2.76-fold ratios use different comparison baselines. These saved-input 500-update runs exclude upstream GWAS preparation and do not establish convergence.
- **Latest incremental extension:** `docs/experiments/compiled-moments/README.md` and its compressed evidence record exact paired exports, numeric checkpoints, and support selections; T2D 339.138 to 316.652 s and NAFLD 126.236 to 112.576 s. Alternative NAFLD control gives only 1.053-fold; process memory varies. Do not multiply these gains into the historical 20.04-fold result.
- **Numerical stopping repair:** `docs/experiments/inner-rhat-stability/README.md` and `docs/GIBBS_OPTIMIZATIONS.md` describe the default repair. It affects the mean-stopping copy only. It is documented separately from arithmetic speedups, with no general mixing claim.
- **Excluded:** incremental residual caching, conditional-mean inference, early stopping experiments, independent fPS/variance branches, abandoned debug work, and prior rejected inference replacements are not described as retained improvements.
- **Sampling section:** explicitly provisional. Collapsed support updates and support swaps are two composable components; no full-model success or production adoption is claimed. The parent experiment should replace this placeholder only if the new logistic and biological evaluation supports that change.

The older scaling section contains historical claims (for example, all arithmetic expressed as NumPy vectorization) that do not describe the new optional compiled implementation. The new section explicitly identifies compiled traversals without silently rewriting that history. The draft also retains the broader model compatibility issue pending the separate target reconciliation; the speedup section is not a certification of posterior correctness.
