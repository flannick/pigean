Created branch `codex/annotation-structure-cache` at `d7c393a`. Implemented an exact per-column LRU cache bounded at 64 MiB retained payload and 16,384 entries, scoped by the existing backend context. Keys include row count and complete dtype/index/value bytes after canonicalization; entries contain only unique values, inverse assignments and counts. Column subsets/reordering reuse entries while mutations cannot hit stale data. Group assembly concatenates arrays rather than extending Python lists. Engine `cached-grouped-regression` is opt-in. Covariance objects/weights and chain-specific mappings remain freshly constructed.

The first test pass found two legacy-reference failures on constant-column SEs. A direct three-engine check confirmed cached and uncached grouped outputs were bit-for-bit identical across every return field; only legacy SEs on the constant-one column differed (all coefficients, other fields, and varying-column SEs agreed). This is inherited cancellation in an unidentifiable intercept/constant-column design, not cache invalidation. The new cache tests now explicitly demand exact equality to its grouped parent on all fields including singular columns, and legacy equality on all fields except those constant-column SEs. No tolerances were loosened. Retain this as a compatibility limitation requiring separate resolution before promotion; do not claim universal legacy-equivalent SEs.

## Completed screen

All six serial screens completed. Each comparison checks driver/fixture hashes, controls, seed, update counts, output universes, missingness, full and top-200 Pearson/Spearman/slopes, and unrounded iteration arrays. Source checkpoints: legacy `8b8c5e6`, grouped `d7c393a`, cached `3a4f75d`.

Cached versus grouped priors, `beta_uncorrected`, and beta iteration arrays are bit-for-bit identical, as are both exported summary columns and their top-200 unions. Against legacy, exports are exact at output precision; Pearson/Spearman correlations and slopes are one within floating-point precision. Maximum internal errors (prior / uncorrected beta / beta) are T2D 8.69083e-13 / 3.72757e-14 / 2.79776e-14 and NAFLD 1.78302e-13 / 7.38298e-15 / 7.38298e-15, unchanged from the previous grouped screen. These comparisons do not test full-trace SE equivalence; retain the documented constant-column limitation.

Cache activity confirms reuse: T2D 7,368 hits / 3,355 misses, 13,616,264 retained payload bytes; NAFLD 1,328 hits / 515 misses, 1,461,560 bytes. Contents stayed below configured bounds. Covariance weights were not retained between regressions. Both initial setup and cache population occur within the measured inference time.

Decision: implemented and screened, retained as a local opt-in checkpoint. Roughly 4% incremental improvements are consistent with the small construction share in profiles, but single timings do not establish a repeatable gain. Do not promote, push, merge, change defaults, or expand to full runs. All four comparisons are `SCREEN_ONLY`; none meet the 10x expansion gate. No convergence claim is supported by these four-update traces. Continue the optimization-only sequence with covariance preparation after this step, and defer combined/convergence discussion until those options have been evaluated.
