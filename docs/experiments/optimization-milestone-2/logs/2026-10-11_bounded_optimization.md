# 2026-10-11 bounded runtime experiment

The user authorized the staged profiling/candidate sequence after cancellation of the oversized legacy panels. Inputs are the frozen T2D and NAFLD pre-Gibbs fixtures under `results/feature_foundation_20261011/fixtures/`, captured from protected main. The source control is foundation commit `8b8c5e6`; experimental work is independent of the fPS and variance-threshold ports.

Created `scripts/screen_inference.py` with explicit fixture checksums, source commit identity, a process time limit, optional cProfile collection, and optional gzip summary/iteration-array outputs. Only total/epoch iteration budgets are shortened; original chain counts and inner-sampler controls are retained. Commands use the shared analysis Python environment. Initial profiles used a five-iteration budget and 140-second process cap each, with `--profile`; both completed. The profile records four executed outer updates at this short budget, rather than five. These early iterations are not a full-run performance estimate or convergence test.

Profiled inference time was 42.651 seconds for T2D and 9.037 seconds for NAFLD. Marginal covariance inflation consumed 32.074 seconds (75.2%) and 7.153 seconds (79.2%), respectively. The broader marginal-regression preparation took 41.201 seconds and 8.396 seconds. Covariance-only acceleration is therefore bounded near four to five times on these early traces; a tenfold candidate needs to accelerate the rest of regression as well. Profile files and receipts are under `results/bounded_optimization_20261011/profile_T2D/` and `profile_NAFLD/`.

Implemented an opt-in sparse marginal-regression backend in `worktrees/sparse-marginal-regression/`, branch `codex/sparse-marginal-regression`, local checkpoint `ff4e4ce`. The flag is `--gibbs-engine sparse-regression`; default/explicit `legacy` behavior remains selectable. Sparse covariance uses the exact constant-plus-sparse influence decomposition, including an independent pseudocount contribution and fallback for cancellation or covariance operators. Sparse IRLS evaluates the same sufficient sums directly, retaining probability caps, convergence rules, and the existing pseudocount estimator. This is arithmetic optimization, not a sampler or posterior approximation.

Focused numerical, covariance, CLI, and replay tests passed: 40 tests in 35.34 seconds, recorded in `tests_before_screen.txt`. An earlier invocation lacked PYTHONPATH for subprocess tests and failed two import checks; the corrected invocation passed. The new equivalence tests cover weighted/binary annotations, trait-specific covariance, constant outcomes, cancellation, extreme coefficients, and opt-in dispatch with context cleanup. No source changes were made after this passing run except the candidate's explanatory document before committing.

The paired screen uses one seed, identical fixtures and controls, and the same analysis driver for each backend. A diagnostic-hook signature error interrupted the first T2D control before output collection; its ERROR receipt was retained, the hook was corrected to accept positional state, and a fresh output directory was used for the retry. This was a screening-script error, not a sampler failure. Iteration arrays provide a numerical comparison during burn-in, separately from exported posterior summaries. No full trait fits are authorized automatically by a short output match.

## Paired-screen result and stopping decision

Completed one paired, unprofiled short replay per trait, serially, with seed 0 and a five-iteration budget (four executed outer updates). T2D legacy/candidate inference times were 42.277/18.606 seconds, a 2.272x ratio. NAFLD times were 8.907/3.664 seconds, a 2.431x ratio. Whole screening-process times, including fixture loading and output writing, were 56.155/32.840 seconds for T2D and 21.952/16.603 seconds for NAFLD; these are not end-to-end raw-GWAS or full-iteration benchmarks.

Used `scripts/compare_inference_screen.py` to compare complete finite output universes and the union of top-200 panels. Exported gene priors and `beta_uncorrected` were exactly equal at output precision for both traits, with correlations and slopes numerically one and identical missingness. The iteration arrays also matched: maximum prior difference was 8.75e-13 (T2D) and 1.86e-13 (NAFLD); maximum uncorrected-beta differences were 3.62e-14 and 7.25e-15. Arrays include early/burn-in updates and are explicitly not converged-posterior evidence. Comparison records are `comparison_T2D.json` and `comparison_NAFLD.json` under `results/bounded_optimization_20261011/`.

The candidate does not meet the tenfold requirement. Stopped at screening: no full 500-iteration fits, additional seed panels, timing repeats, push, merge, or default change. Checkpoint `ff4e4ce` remains available locally as a possible arithmetic component; no mixing improvement is expected from this change. Next work should address how many expensive regressions are required or introduce a statistically justified approximation. All launched screening processes completed and no sampling jobs remain active.
